# Políticas epistemológicas

Regras constitucionais do sistema (§3, §7, §39). Nunca convertem silenciosamente
hipótese em fato.

- **Similaridade não é identidade** (P4): score alto de nome não prova mesma pessoa.
- **Correlação não é causalidade** (§31): associação quantitativa entre variáveis
  não demonstra atribuição causal; exige evidência adicional.
- **Ausência não é inexistência** (§49 do blueprint conceitual): falta de registro
  não prova que o fato não ocorreu.
- **Outlier não é ilicitude** (§30): registro atípico admite explicações (erro,
  comportamento raro legítimo, diferença de fonte, transformação incorreta).
- **Representação temporal não é verdade temporal** (P6): converter timezone não
  valida sincronização de relógio.
- **Achado exploratório não é conclusão** (§28-29): a escada epistemológica
  (descrição → padrão → associação → hipótese → inferência → conclusão) não admite
  salto silencioso entre níveis.

Status epistemológicos possíveis: OBSERVED, DERIVED, CANDIDATE, POSSIBLE,
VALIDATED, VALIDATED_WITH_RESERVATIONS, DISPUTED, REJECTED, UNKNOWN (§9).
